## 📌 Overview

News-Data-Scrapper-for-Indian-Express-News helps you collect news data from Indian Express pages on a Windows computer. It uses Selenium and Python to open the site, read page content, and save the data for later use.

Use it when you want to gather news text, headlines, dates, links, and related page details without copying each item by hand.

## 🚀 How to Set It Up on Windows

### 1. Open the download page

Go to the GitHub link above in your browser.  
If you see a green or blue button for files, use that to get the project.

### 2. Get the project files

If the repository offers a ZIP file, download it to your computer.  
If you are using Git, you can also clone the repository to a folder on your PC.

### 3. Extract the files

If you downloaded a ZIP file:

- Find the ZIP file in your Downloads folder
- Right-click it
- Select Extract All
- Choose a folder you can find again, such as Desktop or Documents

### 4. Open the project folder

After extracting the files, open the folder that contains the project.  
Look for files such as:

- `main.py`
- `requirements.txt`
- `README.md`
- folders named `src`, `data`, or `output`

### 5. Install Python

If Python is not on your computer:

- Download Python from the official Python website
- Install the latest stable version
- During setup, check the box that says Add Python to PATH

### 6. Open Command Prompt

In the project folder:

- Click the address bar in File Explorer
- Type `cmd`
- Press Enter

A Command Prompt window will open in that folder.

### 7. Install the required packages

Type this command and press Enter:

`pip install -r requirements.txt`

If the project does not use a `requirements.txt` file, install the main tools used by the app:

`pip install selenium beautifulsoup4 pandas requests`

### 8. Make sure Chrome is ready

This scraper works with Google Chrome.  
Open Chrome once before you run the app so it is set up on your PC.

### 9. Run the scraper

If the main file is named `main.py`, use:

`python main.py`

If the file has a different name, use that file name instead.
